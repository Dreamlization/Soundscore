# 声谱工坊 (Soundscore v4.2)

本项目是一个纯前端构建的 AI 音频扒谱与音色分离工作站（概念演示版 v4）。
在此版本中，我们对项目进行了深度的工程化重构与细节打磨，实现了完全离线可用、结构清晰、跨平台兼容的专业级前端代码库。

项目详细分工已添加至“关于我们”页面下的“项目详细分工”弹窗中。

## 目录结构

```text
Soundscore_v4/
├── docs/                 # 项目文档与设计参考图
│   ├── AI_CONTEXT_V3.md
│   └── design/           # 界面设计参考图

│   ├── audios/           # 演示用的音频文件

│       └── webfonts/     # 字体文件 (包含 NotoMusic 音符字体与 FontAwesome)
├── src/                  # 前端核心业务代码
│   ├── components/       # 公共 Vue 组件 (Header, Modals 等)

│   ├── store.js          # 全局状态管理与缓存校验逻辑
```

## 运行方式

本项目采用原生前端技术栈构建，**零依赖安装、零构建过程**，且所有资源（包括框架、字体、图标）均已本地化。
您只需通过任意本地静态服务器（如 `Live Server`, `python -m http.server`, `npx http-server` 等）在根目录启动，然后在浏览器中打开 `index.html` 即可完整体验。

## V4 核心优化与更新亮点

### 1. 工程化与结构重构

- **资源分类精细化**：彻底告别根目录资源堆叠，将所有图片拆分为 `avatars`、`covers`、`ui` 三大模块，所有代码引用同步更新。
- **数据抽离**：庞大的预设乐谱数据被统一移入 `src/data/` 目录，实现了代码与数据的解耦。
- **CSS 外部化**：提取了原本臃肿的内联 `<style>`，建立 `public/css/global.css` 进行统一的全局样式管理。
- **无用代码清理**：删除了早期版本遗留的废弃脚本与冗余文件。

### 2. 跨平台兼容性保障

- **完美音符渲染**：引入并物理内嵌了开源的 `Noto Music` 字体至 `webfonts` 目录。
- **精准的字形度量**：针对新字体优化了工作台中音符的 `rem` 缩放比例，使音符适配五线谱线宽。

### 3. 交互逻辑与体验升级

- **缓存自愈机制**：在 `store.js` 与 `app.js` 中增加了登录状态的初始化校验，自动修正了因文件结构调整导致的旧 localStorage 缓存头像破损问题。
- **智能谱号显示**：工作台五线谱首部的谱号不再是固定写死，现已支持基于乐曲动态计算。
- **无缝导出体验**：修改了工作台的导出逻辑，防止离开当前正在编辑的工作台界面。

### 4. 继承自原有版本的功能

- **画廊级教程图墙**与极具科技感的 3D 视觉首页。
- **多行五线谱系统**：支持 100 行智能分页与自动翻页跟播。
- **交互排版引擎**：动态光标、逆转模式 (180° 倒置音符)、全能拖拽重排与擦除。
- **智能分析**：一键简化和弦、多轨独立分离与导出。
- **防错机制**：基于快照栈的 50 步撤销/恢复功能。
- **权限隔离**：完善的普通用户注册体系与拥有 Pro 权限的 Admin 管理员账号分离机制。
