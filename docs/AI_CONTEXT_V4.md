# “声谱工坊”前端信息架构与互动逻辑参考

本文档基于“声谱工坊”（Soundscore AI）的初始设计需求整理，网站核心功能为“AI 音频扒谱与音色分离”,仅需要设计前端功能，无需考虑后端部分，整体呈现风格为黑粉色系，确保核心功能突出、使用方便，同时保证这一前端无需复杂的配置过程也能在任意电脑上打开。
本文档旨在为后续 Vibe Coding 快速生成前端界面提供详尽的页面结构、数据展示和交互逻辑参考。

## 1. 首页 (Home)

### 1.1 首屏看板

*注：整体设计参考首页参考设计.jpg，采用左右结构设计，全局导航栏可采用黑粉格点形式。整个首页的文本要求**无法选中**（鼠标悬停时不显示文本选择的光标）。*

- **首屏左右结构布局**
  - **左侧（品牌传达与核心操作）**：
    - **主标题**：“声谱工坊”展示网站核心名称，需使用**荧光粉色**进行强调。
    - **副标题 / 定位 (Slogan)**：“AI 音频扒谱与音色分离工作站”展示产品定位，要求使用**黑体、白色、加粗强调**，并且必须在**一行内显示完毕**，不得换行。
    - **极速处理入口**：展示核心的上传交互区。
  - **右侧（产品展示）**：
    - **工作台实机演示**：表现为一部在立体空间中**倾斜放置、朝向屏幕右侧，且必须展示出包含键盘面的完整透视结构**的笔记本电脑，电脑屏幕中的图案是本网站的编辑界面。同时在电脑下方需要有**效果明显、包含更多音符的流动的五线谱视觉特效**（深度复现参考图中的视觉）。
- **使用教程视频区**：在首屏下方预留出一个明显的位置，用于放置视频教程。该视频占位需使用**电子音乐风格的默认封面**，不展示占位文字。

### 1.2 极速处理入口（核心交互区）

- **上传说明区**
  - **支持格式与大小提示**：“仅支持 MP3/WAV”、“单文件最大 50MB”说明文本需放置在**上传框的下方**，要求**整体左对齐**，且前方的对勾标记使用**绿色**。
- **上传交互区**
  - **上传触发器**：`[操作]` 支持文件拖拽拽入区域 / **点击上传框的任意部分**即可唤起本地系统文件选择器。
  - **文件前端校验**：`[系统规则]`
    - **格式或大小不符**：`[操作]` 触发拦截，弹出全局 Toast 报错提示（如“不支持该格式”“文件过大”），终止上传
  - **上传处理中状态**：`[局部视图]`
    - **动态视觉反馈**：`[展示]` 如骨架屏或扫描动效（可结合粉色呼吸灯效强调 AI 感）
    - **上传进度指示器**：`[动态数据]` 0%-100% 实时进度
    - **取消上传按钮**：`[操作]` 中断传输进程，清空数据，**立刻停止上传并停留在首页，绝不进入编辑界面**
  - **上传完成路由分发**：`[系统规则]`
    - **分支 A（检测到已登录）**：`[操作]` 携带音频缓存数据，直接跳转至「2. 工作台」并自动触发 AI 分离任务
    - **分支 B（检测到未登录）**：`[操作]` 暂停业务流，唤起「登录/注册」拦截弹窗

### 1.3 「登录/注册」拦截弹窗

*注：本项目采用纯前端 JS 实现模拟登录与注册。设定一个硬编码的“管理员账号”（admin / 710049）。该管理员账号已开启专业版（Pro），能够正常使用专业版的所有服务（包括导出时的各项功能都开放使用），个人中心中的“订阅计划”、“创作数据”在显示上应和普通用户有所区别。普通用户注册的新账号未开启专业版，鼠标在头像上悬浮的弹窗中不应显示“专业版”字样。*

- **弹窗容器控件**：`[信息与操作]`

  - **模式切换**：`[操作]` 支持在「登录」和「注册」两个面板间无缝切换。
  - **关闭弹窗按钮 (X)**：`[操作]` 销毁弹窗，若是由上传触发的拦截，则丢弃已上传的临时音频，停留在首页。
- **【登录面板】**：

  - **账号与密码输入框**：`[数据输入]`
  - **确认登录动作**：`[核心操作]`
    - **路由逻辑分支**：
      - *情景 1（首页主动点击登录）*：登录成功后销毁弹窗，**停留在首页**，更新右上角用户状态。
      - *情景 2（上传音频被拦截）*：登录成功后销毁弹窗，直接携带音频跳转至「2. 工作台」并触发 AI 解析。
    - **错误提示**：`[展示]` 提示“账号或密码错误”。
- **【注册面板】**：

  - **表单字段**：`[数据输入与验证]` 所有内容均各占一行，并且各项表单字段（如“用户名”、“密码”、“确认密码”）均应注明在输入框上部左侧。
    - **用户头像**：`[操作]` 点击选择预设头像或上传（前端模拟）。
    - **用户名**（必填）。
    - **密码 & 确认密码**（必填，输入框右侧附带白色的显示/隐藏密码切换 Icon）。
    - **用户邮箱**（可选）。
    - **个人简介**（可选）。
    - **生日**（必填，日期选择器，占位符直接显示为“yyyy/mm/dd”，右侧的日历 Icon 需保证为白色）。
    - **个人身份**：`[操作]` 下拉单选（音乐专业学生、音乐爱好者、音乐从业者、音乐教师、其他）。
  - **合规与安全校验**：`[操作]`
    - **人机验证**：勾选“我承诺不是机器人”复选框。
    - **协议同意**：勾选“已阅读并同意《用户服务协议》和《隐私政策》”。
      - *交互优化*：协议链接点击后，**在当前页面唤起层叠弹窗查看协议内容**，而不是跳出页面（详见 6.3）。
  - **确认注册动作**：`[核心操作]` 校验表单通过后，将新用户信息写入 `localStorage`，并自动执行登录状态流转（路由逻辑同登录面板）。

## 2. 工作台 (Workspace)

*注：尽量采用简洁的设计语言和设计风格，可参考编辑界面参考设计.jpg*

### 2.0 AI 处理加载态（过渡状态）

*注：因 AI 处理需耗时，跳转至工作台后需先展示此状态，避免数据断层。*

- **处理中提示**：`[展示]` “AI 正在努力解析音频中，请稍候...”搭配粉色波纹动效
- **分离进度条**：`[动态数据]` 展示 AI 拆分人声与乐器的实时进度
- **处理异常处理**：`[操作]` 若处理失败，展示“解析失败”并提供「重试」或「返回首页」按钮

### 2.1 顶部全局导航栏

*注：在任何情况下，导航栏风格都要保持一致。编辑界面中的导航栏整体结构上应与首页完全一致。*

- **产品 Logo 与名称**：展示“声谱工坊”及 Logo，点击可返回首页。
- **当前音频信息**：当前音频文件名称（如 `Demo_RHCP_Cover.mp3`）。
- **音频元数据**：
  - **时长**：`[数据]` 音频总时长。
  - **速度 (BPM)**：`[数据]` 音频的每分钟节拍数量。
  - **拍号**：`[数据]` 音频的拍号情况。
- **用户操作区**：与首页一致，包含「我的项目」快捷入口与「用户头像」下拉菜单（点击可直达个人中心）。

### 2.2 工具栏（导航栏下方）

*注：参考编辑界面参考设计.jpg，原导航栏右侧的操作按钮下移至工具栏右侧。*

- **左侧：模式选择**
  - **拖动模式**：`[操作]` 抓手 Icon，用于拖拽查看谱面。在此模式下，支持拖拽已经放置的音符或书签来调整位置（遵守垂直方向的吸附规则）。
  - **备注模式**：`[操作]` 铅笔 Icon，用于在五线谱**上方**特定位置添加注释文字。选中该模式点击五线谱上半部分时可添加一个倒置的五边形书签标记，文字以楷体显示在书签上方。只有在此模式下可删除标记和编辑文字，其他模式点击标记仅切换显示/隐藏状态。
  - **擦除模式**：`[操作]` 橡皮 Icon，用于删除五线谱上已放置的音符或用户添加的音符，悬停时音符会放大变红，点击即删除。
- **中部：功能选择（乐理符号库）**
  - 包含 **6 种标准音符**（全音符到三十二分音符，字号设定为 `4rem` 左右）和 **9 种符号**（升降号、休止符等，字号设定较小）。
  - *动态光标交互*：选中音符或符号后，鼠标在谱面上的光标会变成**该符号的半透明粉色形状**，直观指示落点。
- **右侧：高级操作区**
  - **撤销/恢复**：`[操作]` 新增 Undo 和 Redo 按钮，基于状态快照实现（最大 50 步），每次添加、擦除、拖拽等操作前都会自动保存历史记录。
  - **一键简化和弦**：`[操作]` 开关按钮。开启时，谱面原有音符变为 50% 透明度，并在小节中心区域根据音符数量动态生成对应乐器（吉他/键盘）的和弦名称块。
  - **保存项目**：`[操作]` 保存当前进度。
  - **导出 MIDI/PDF**：`[操作]` 唤起「导出配置」弹窗。

### 2.3 谱面显示（中心核心区）

- **独立乐器五线谱 (A4 风格) 与分页系统**：`[展示/可交互]`
  - 谱面采用白底黑字。排版紧凑。
  - **分页与滚动**：乐谱扩容至 **100 行**，采用分页机制。第一页包含标题与音频信息（最多 8 行），后续页面无标题（最多 10 行）。左右两侧有悬浮翻页按钮，右下角有 `Page X/Y` 指示器。播放时支持**自动翻页跟随**。
  - 谱面上自动生成可编辑的音符群（每小节生成 6~8 个音符，仅包含 6 种标准音符，无重叠）。
  - **小节划分与辅助线**：
    - 每行容纳 **2 个小节**。
    - 每个小节之间使用**黑实线**进行分割。
    - 每个小节内有 **3 条灰色辅助线**，将小节四等分。
- **音符编辑与自动吸附**：`[展示/操作]`
  - *自动吸附逻辑*：添加或拖拽音符时，垂直方向会严格吸附到五线谱的**线或间**上（9个档位）。水平方向保留自由坐标（不强制吸附拍子），赋予用户更大排版自由度。
- **播放进度指示块**：`[动态展示]` 谱面后方有一个悬浮的小指示块，与底部的播放进度条联动，实时指示当前播放到的具体位置。

### 2.4 左侧智能混音台与乐器切换

- **各独立乐器音轨**：包含人声 / 鼓组 / 吉他 / 键盘 / 贝斯 / 其他。默认选中「吉他」。
  - **乐器切换**：`[操作]` 点击不同的乐器，中心谱面即切换至对应的五线谱版本。
    - *限制条件*：「人声 Vocal」轨道点击时展示为“功能暂未开放，无法选择”。
  - **乐器 Icon 与名称**：`[数据/展示]` 显示当前音轨乐器。
  - **单轨独立扒谱器**：`[操作]` 悬浮于乐器 Icon 唤起，点击后提取该轨乐谱（即切换至该乐器谱面）。
  - **音轨音量滑块**：`[操作]` 横向拖拽调节当前轨音量，右侧跟随 0%-100% 数值展示。
  - **Mute (静音) 按钮**：`[操作]` 状态切换开关。
  - **Solo (独奏) 按钮**：`[操作]` 状态切换开关，与其他轨道互斥逻辑。

### 2.5 一键简化和弦功能详细逻辑

- **功能约束**：该功能仅在当前选中的乐器为「吉他」或「键盘」时才可用，其他乐器下呈置灰不可点击状态。
- **状态锁定机制**：
  - 当功能**开启**时，工具栏的音符编辑功能（添加、擦除）被锁定不可用，只能选择「拖动模式」与「备注模式」。
- **和弦生成规则**：
  - `[展示数据]` 在五线谱上方显示小节对应的简化和弦名称（通常每小节 2 个，极少部分为 1 个）。
  - *和弦库参考*：
    - **吉他**：C, G, D, A, E, Em, Am, F, G7 等。
    - **键盘**：C, G, F, Am, Dm, Em, Cmaj7, G7, Fmaj7 等。

### 2.6 底部播放控制区

- **基础播放器**
  - **播放 / 暂停**：`[操作]` 真实制作控制播放状态的功能。在播放状态中，中心乐谱的进度指示块和下方的全局时间轴滑块必须能够自动移动。
  - **快退 10s / 快进 10s**：`[操作]` 按钮应与播放/暂停键更靠近，并且使用明确的标识（如向后双箭头、向前双箭头图标）来明确其“快退10s”、“快进10s”的作用。
- **全局时间轴**
  - **播放进度条**：`[数据/操作]` 支持拖拽滚动条定位，显示的时间应与音频时长一致。拖动滑块时，中心乐谱界面的指示块需同步在不同行之间切换与移动。
- **播放倍速调节**：`[操作]` 调节播放速度

### 2.7 「导出配置」弹窗

- **弹窗标题与关闭 (X)**：`[信息/操作]` 销毁弹窗
- **格式选择**：`[操作]` 单选标签 (PDF / MIDI / GP / MSCZ)
  - *注意*：`[操作]` 点击带有 Pro 标识的格式（如 MIDI / GP / MSCZ），唤起「升级会员」弹窗，而非直接跳走
- **导出范围**：`[操作]` 下拉选择（不同音轨）
- **确认导出按钮**：`[核心操作]` 触发打包并唤起本地下载
- **取消按钮**：`[操作]` 销毁弹窗

## 3. 我的项目 (My Projects)

### 3.1 页面全局标头

- **页面标题文本**：`[展示数据]` 如“我的项目”

### 3.2 项目操作与检索区

- **全局新建动作**
  - **上传新项目按钮**：`[操作]` 唤起本地文件选择器，校验后上传并直跳「2. 工作台」

### 3.3 项目列表看板

- **空白缺省态**
  - **缺省视觉插画**：`[展示]` 体现无数据状态
  - **引导文案**：`[说明]` 如“暂无项目，快去上传并生成你的第一份乐谱吧”
  - **快捷上传按钮**：`[操作]` 同全局新建动作
- **数据列表区**
  - **项目属性卡片 (单条数据元)**：`[信息分组]`
    - **歌曲封面图**：`[展示数据]` 专辑图或系统默认占位图

    - **音乐元数据缩略**：`[展示数据]` 如时长

    - **删除按钮**：`[高危操作]` 点击唤起「删除确认」弹窗

### 3.4 「删除确认」弹窗

- **警告图标与标题**：`[展示]`
- **确认文案**：`[数据/说明]` 如“确定要删除 XXX 吗？此操作不可撤销。”
- **取消按钮**：`[操作]` 销毁弹窗
- **确认删除按钮**：`[操作]` 触发后端删除接口，成功后销毁弹窗，前端移除该列表项并提示“删除成功”

### 3.5 分页与加载控件

- **页码指示器 / 翻页按钮**：`[操作]` 若项目较多，控制列表翻页加载

## 7. 视觉与交互规范 (Design Tokens - 黑粉色系)

*注：针对“整体呈现风格为黑粉色系，确保核心功能突出”的额外补充设计规范。*

- **色彩规范 (Color Palette)**：
  - **主背景色**：深邃黑 / 深灰 (如 `#121212` 或 `#1A1A1A`)，营造专业工作站氛围。
  - **主品牌色 (Primary)**：更偏向粉色而非红色 (建议采用 `#FF69B4` / `#FF1493` 类型的粉色系)，用于核心按钮、高亮文字、特效与进度条等。
  - **辅助/警示色**：柔和的灰白色用于普通文本，红色用于删除等高危操作。
- **视觉层级与动效**：
  - **科技感**：在“上传处理中”与“工作台 AI 处理”阶段，大量运用粉色呼吸灯、发光描边或波纹动效。
  - **高对比度强调**：核心操作区域（如首屏的极速处理入口）应具备明显的粉色视觉焦点，确保用户视线第一时间被捕获。
